# 🧱 Nextalism

A minimalist Next.js app template with Neobrutalism UI.

- [Next.js](https://nextjs.org/)
- [Neobrutalism](https://neobrutalism.dev/)
- [Prisma ORM](https://prisma.io/orm)

## Getting Started

1. Clone the repository or "use this template".

   ```bash
   git clone git@github.com:aglabsid/nextalism.git
   ```

2. Copy the `.env.sample` file to `.env` and set your environment variables.

   ```bash
   cp .env.sample .env
   ```

3. Install the dependencies.

   ```bash
   pnpm install
   ```

4. Sync prisma schema with the database.

   ```bash
   pnpm db:push
   ```

5. Start the development server.

   ```bash
    pnpm dev
   ```
